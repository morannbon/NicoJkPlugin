# NicoJkPlugin v1.0.4

## v1.0.4 の更新内容

- TvAIrのネットワーク利用設定に対応しました。TvAIr全体の「ネットワーク利用」とNicoJkPlugin個別の「インターネット接続を許可する」が有効な場合のみ、実況コメント取得のための外部通信を行います。
- ネットワーク利用をOFFにした場合、録画や視聴を継続したまま実況コメント通信を停止し、再びONにすると進行中の録画セッションでコメント受信を再開できるようにしました。
- 録画開始と実況コメント取得開始が前後した場合でも、対象番組の実況セッションを正しく開始できるよう安定性を改善しました。
- 録画の切り替わりや連続録画時の実況セッション終了・開始処理を改善し、コメント保存と次の番組への切り替えを安定化しました。
- 視聴状態の切り替わり時に古いコメント表示状態が残らないよう、視聴画面へのコメント表示処理を改善しました。

## 製品説明

NicoJkPluginは、TvAIrで録画中の番組に対応するNicoJKコメントを取得し、コメント保存、時系列テキスト配信、視聴画面へのコメント表示を行うTvAIr用プラグインです。

### 主な機能

- 録画中の番組に対応するNicoJK実況チャンネルを解決し、コメントを取得します。
- 取得したコメントを録画後利用向けに保存します。
- TvAIrへ時系列テキストとしてコメントを配信します。
- 視聴画面へ実況コメントを表示します。
- 既存のNicoJK設定を自動的に読み込みます。

### 動作環境

- TvAIr 1.2.2以上
- .NET 8 Windows
- x64 / x86
- ソースからビルドする場合はVisual Studio 2022

## 導入・使い方

### インストール

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `NicoJkPlugin.sln` を開きます。
3. 使用するTvAIrのアーキテクチャに合わせ、`Release / x64` または `Release / x86` でビルドします。
4. TvAIrを終了します。
5. 生成された `NicoJkPlugin.dll` と、ソース直下の `plugin.json` をTvAIrのプラグイン配置先へコピーします。
6. TvAIrを起動し、NicoJkPluginが読み込まれていることを確認します。

### 設定と通信条件

既存のNicoJK設定を自動的に読み込むため、通常は追加設定不要です。

NicoJkPluginの「インターネット接続を許可する」は初期状態では無効です。実況コメントを取得するには、TvAIr側で次の両方を有効にしてください。

1. TvAIr全体の「ネットワーク利用」
2. NicoJkPluginの「インターネット接続を許可する」

どちらかがOFFの場合、NicoJkPluginは実況コメント取得のための外部通信を行いません。録画や視聴自体は継続します。通信を再び許可すると、対象の録画セッションが継続中であればコメント受信を再開します。

NicoJkPlugin独自の通信ON/OFF設定はありません。通信の実効状態はTvAIr側の設定に従います。

### 状態表示

NicoJK画面では、現在の状態を「正常」「実況受信中」「実況対象外」「接続できません」で確認できます。

### 更新方法

1. TvAIrを終了します。
2. 新しい版でビルドした `NicoJkPlugin.dll` と `plugin.json` を既存ファイルへ上書きします。
3. TvAIrを起動し、NicoJkPluginが正常に読み込まれていることを確認します。

既存のNicoJK設定はそのまま利用できます。

## 注意事項

- NicoJKコメントを取得するにはインターネット接続が必要です。
- 外部サービスの停止、仕様変更、通信障害等によりコメントを取得できない場合があります。
- 本プラグインはTVTest用NicoJK本体の同梱版・改変版・後継版ではありません。
