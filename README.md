# NicoJkPlugin 1.0.0

NicoJkPluginは、TvAIr上で録画中の番組に対応するニコニコ実況コメントを取得し、TvAIrのライブコメント表示および録画後再生用コメント保存に連携するためのTvAIr用プラグインです。

メニューからはプラグイン情報の小窓を表示します。内部状態ページは表示しません。

## 主な機能

- TvAIrの録画セッションを監視し、対応するニコニコ実況チャンネルを解決します。
- 取得した実況コメントをTvAIrのライブコメント表示へ連携します。
- 録画後再生用のコメント保存に対応します。
- 既存のTVTest/NicoJK環境との互換性のため、ユーザー環境にある`NicoJK.ini`およびBonDriverの`ch2`ファイルを参照する場合があります。

## インストール方法

1. Visual Studio 2022で `NicoJkPlugin.sln` を開きます。
2. 構成を `Release x64` にしてビルドします。
3. ビルド後の `deploy/NicoJkPlugin.dll` をTvAIrの `Plugins/NicoJkPlugin.dll` として配置します。
4. TvAIrを再起動し、プラグイン一覧でNicoJkPluginが読み込まれることを確認してください。

## 関連ソフトウェアとの関係

本プラグインは、TvAIr上でニコニコ実況コメント連携を行うために作成されたTvAIr用プラグインです。TVTest用プラグインとして公開されているNicoJK本体の同梱版、改変版、後継版ではありません。

NicoJK本体、NicoJK.tvtp、jkcnsl.exe等は本配布物には含みません。外部ソフトウェアを利用する場合は、それぞれの配布元のライセンスおよび利用条件に従ってください。

詳細は `NOTICE.md` を参照してください。
